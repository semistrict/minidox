# Security policy

## Supported versions

This project is an experimental prototype and currently has no supported
release or security-update window.

## Reporting a vulnerability

Please do not open a public issue containing vulnerability details. Use GitHub's
private vulnerability reporting if the repository exposes a **Report a
vulnerability** button. Otherwise, open a minimal issue asking the maintainers
for a private contact channel without including sensitive details. Include the
affected revision, host and guest configuration, impact, and reproduction
details in the private report when possible.
